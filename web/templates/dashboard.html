Метрики считаются в браузере из ваших реальных прогнозов на фиксированной тестовой выборке. Строка source_line связывает прогноз с записью Faults.NNA.

Матрица ошибок

Строки — истинная категория, столбцы — прогноз модели.

Метрики по категориям

F1 по семи типам дефектов. Центр соответствует 0, внешний контур — 1.

Разрыв топ-2 (margin)

Распределение margin: чем меньше разрыв, тем менее уверена модель. Низкий margin — первый критерий очереди проверки.

Спорные записи

Строки, где ошиблись все три модели (top3_errors = 3) — кандидаты на пересмотр разметки.

Мониторинг сдвига

—

Повторяет faults/drift.py: KS-статистика по каждому признаку, порог — 95-й квантиль максимума по 96 розыгрышам калибровочной выборки. Минимум 30 записей.

KS по признакам

Отсортировано по убыванию. Признаки яркости из BRIGHTNESS подсвечены — именно они меняются в демо-сдвиге.
